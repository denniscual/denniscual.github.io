Redev

React DevTools with an AI chat assistant built in — analyze component hierarchies and debug performance bottlenecks without leaving Chrome DevTools.

What it does

  • Components & Profiler panels — the full React DevTools experience: inspect the component tree, view and edit props/state/hooks, profile rendering performance.
  • AI assistant in the panel — ask questions about the inspected app ("Why is this component re-rendering?", "Show me this component's implementation") and the assistant inspects trees, profiles, and source maps to answer with evidence.
  • Reads original source — when the inspected app ships source maps, the assistant reads the original component source, not the minified bundle.
  • Bring your own AI provider — works with a local Ollama instance (fully offline) or an OpenAI account. Your data goes to the provider you configure, and nowhere else.

Privacy

Redev has no servers, no telemetry, and no analytics. Debugging context is sent only to the AI provider you explicitly configure, only when you ask a question. Read the full privacy policy.
